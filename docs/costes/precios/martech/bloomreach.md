# Costes — Bloomreach Engagement

## 1. Modelo de precios

- **Unidad de facturación:** cuota por módulo (email, SMS, búsqueda…) + cuota de uso escalonada[^br-pricing].
- **Qué incluye:** Todos los planes incluyen Loomi AI, soporte, documentación y sesiones de buenas prácticas.
- **Mínimos y compromisos:** Facturación anual obligatoria; el uso por encima del contrato se factura aparte.
- **Precio de lista:** Sin importes públicos.[^br-pricing]
